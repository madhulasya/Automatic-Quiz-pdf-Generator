# Quiz Engine 🧠

A full-stack web application for testing programming knowledge, earning certificates, and creating custom quizzes. Built with **React**, **Node.js**, **Express**, and **MySQL**.

## ✨ Features

- **User Authentication** – Secure signup/login with JWT and bcrypt.
- **Role-Based Access** – Admin and regular user roles.
- **8 Programming Modules** – JavaScript, Python, Java, React, Node.js, SQL, HTML/CSS, TypeScript.
- **Timed Quizzes** – 20 questions per module (configurable), with countdown timer.
- **Automatic Scoring** – Instant feedback and detailed answer review.
- **PDF Certificates** – Download professional certificates for scores ≥ 75%.
- **User Dashboard** – Track quiz history, average score, and certificates.
- **Admin Dashboard** – Create, manage, and delete quizzes; view user performance.
- **User-Generated Quizzes** – Any user can create and share their own quizzes.
- **Profile Management** – Edit bio, location, social links, and view activity.
- **Responsive UI** – Modern, mobile-friendly design with Tailwind CSS.
